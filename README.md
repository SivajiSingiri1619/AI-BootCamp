# Day 2 - Lab 2A - Six Pattern Drills

## Pattern Comparison Matrix

| Pattern | Self Score | Peer Score | Verdict |

| System Prompt | 4/5 | 8/10 | Great for reusable instructions |
| Prompt Chaining | 5/5 | 10/10 | Produces highest quality output for complex tasks |

## Conclusion

I learned six different prompting patterns and how they affect AI responses.

Chain of Thought and Prompt Chaining produced the most detailed and accurate explanations.

For placement-prep students, I will mainly use Persona and Prompt Chaining because they provide targeted and structured learning experiences.
